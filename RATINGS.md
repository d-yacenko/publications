# ВАК, Белый список и применимость для защиты

Проверка 24.11.2026. Предварительный аудит всех записей; не является заключением диссовета. Категории К1–К3, уровни ЕГПНИ, индексация и факт публикации — разные признаки. Не подтверждено не означает отсутствует. Актуальная редакция перечня ВАК от 02.11.2026 обнаружена, но полный файл не удалось сверить; категории ниже подтверждены по доступной копии распределения 2024–2025, а не по полной редакции ноября 2026. Специальности требуют повторной сверки по актуальному перечню и на дату публикации.

## Для защиты

Две статьи в К1 и две в К2 по распределению с 01.01.2024 — предварительные кандидаты. Статья 2020 требует исторической проверки. Не засчитывать автоматически материалы конференций Scopus, главы книг, датасеты и перевод той же статьи. Проверить шифр специальности, отрасль науки, соответствие теме диссертации, дату публикации и локальные требования совета. Для Медицинской техники требуется актуальный документ о приравнивании и подтверждение выхода номера. Полный перечень от 02.11.2026, архивы 2000/2020 и правила конкретного совета остаются открытыми задачами.
